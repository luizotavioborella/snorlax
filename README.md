# 💤 Snorlax Pokédex

An interactive web page focused on Snorlax, developed with HTML, CSS and JavaScript.

This project was created as a frontend activity during the Systems Development course at SENAI to practice JavaScript objects, functions, events and DOM manipulation.

## ✨ Features

- Snorlax Pokédex information
- Dynamic health and energy bars
- Pokémon stats display
- Main and secondary attacks
- Interactive actions
- Attack system
- Health and energy recovery
- Dynamic messages
- Interface updates through JavaScript
